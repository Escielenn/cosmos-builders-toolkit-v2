Theme matrix — 70 themes, zero contrast failures

Every card is one theme: base × primary accent. Each is solved against the same targets as the default palette, so a user can pick any combination and the result passes WCAG by construction. The four semantic accents (Physics, Stop, Worlds, Lore) keep their meaning in every theme.
